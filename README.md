# Rahhal — Moving & Shipping Services

## Overview
**Rahhal** is a modern website for a professional moving and shipping company.  
The project was **fully designed by Me - fatmamohamed (UI/UX) on Figma**, then implemented and developed using **Angular** and **Tailwind CSS**.  

The platform provides a smooth experience for users to explore moving & shipping services such as furniture moving, packing, and parcel shipping (land, sea, air), with the ability to book service packages easily.

---

## Features
- Landing page with company introduction  
- Service packages: same-building, same-city, city-to-city, country-to-country  
- Booking system and pricing plans  
- Partners / Clients section  
- FAQ & Contact pages  
- Responsive design for all devices  

---

## UI/UX Design
- Designed entirely in **Figma** (wireframes, user flow, and final UI screens).  
- Focused on clean layout, usability, and responsive design.  
- Converted into Angular components while keeping consistency with the Figma design.  

---
